# AGENTS.md — apps/ml-crop

> Python/FastAPI service. Port 8010. Crop recommendation, yield prediction, fertilizer recommendation.
> Read root AGENTS.md first, then this file.

## Service Responsibility

Serves three pre-trained scikit-learn models via FastAPI. Models are loaded once at
startup via `lifespan`. No database access — pure stateless inference.

Owns:
- `crop_model.pkl` (RandomForestClassifier, 7 features)
- `yield_model.pkl` (GradientBoostingRegressor)
- `fertilizer_model.pkl` (RandomForestClassifier, 8 features)

## Key Invariants

- **Model load failure = startup failure.** If any `.pkl` is missing, log the path and do NOT bind to port.
- **Batch limit:** max 50 records per batch request. Return `422 batch_limit_exceeded` on 51+.
- **Response time:** single inference < 200ms, batch 50 < 500ms.
- **HMAC auth:** all endpoints require valid `X-User-ID` + `X-HMAC-Signature` + `X-Timestamp`.
- **No model reloading at runtime.** Models are loaded once in `lifespan`. Restart the service to reload.
- **Training reproducibility:** `random_state=42` in all sklearn estimators. Always.

## Model Metadata

Each saved `.pkl` must include a metadata dict:
```python
{
    "trained_at": "2025-05-24T...",
    "val_accuracy": 0.97,
    "features": ["N", "P", "K", "temperature", "humidity", "ph", "rainfall"],
    "classes": ["rice", "wheat", ...]  # for classifiers
}
```
Use `joblib.dump({"model": clf, "metadata": meta}, path)`.

## Critical Pitfalls

- **NEVER** use `print()` — use `logging.getLogger(__name__)`.
- **NEVER** catch bare `Exception` without logging and re-raising as `HTTPException`.
- **NEVER** commit `.pkl` files — they are in `.gitignore`.
- **NEVER** change the feature order in inference without retraining the model.
